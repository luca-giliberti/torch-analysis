# Torch Analysis

An FRC (FIRST Robotics Competition) scouting and match-analysis web app. Load your scouting-data CSVs to rank teams, compare robots, chart metrics, take notes, and build pick lists.

## Live site

Once GitHub Pages is enabled, the app is available at:
`https://<your-username>.github.io/torch-analysis/`

## Usage

Open the site, go to the **Import** tab, and upload your scouting CSV files. Data is cached in your browser (localStorage) — no server or account needed.

## Updating

Edit `index.html`, then:

```bash
git add index.html
git commit -m "Describe your change"
git push
```

GitHub Pages redeploys automatically within a minute or two.
